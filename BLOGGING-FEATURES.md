# What this platform includes

- One HTML file per article  
- Automatic category pages, search index, sitemap  
- Editorial reading layout (TOC for long posts, share, progress)  
- Honest legal pages  

# What it does not include (on purpose)

- Comments, accounts, likes, fake views  
- Fake ads / AdSense  
- Newsletter backend success  
- Social network features  

Knowledge first. Features only if they help discovery, reading, SEO, trust, or publishing scale.
